# The Event Builder

Creating an event on UniTix is done via the Event Builder, which allows you to configure everything from basic descriptions to advanced capacity limits.

## How to Create a New Event
1. Navigate to **Events** in your dashboard sidebar.
2. Click the **Create New** button in the top right.
3. **Basic Info:** Enter the Title, Date, Time, Venue, and Description.
4. **Banner:** Upload a high-resolution 16:9 banner image. This will be the hero image on your public page.

## Setting Venue Capacity
You must set an **Overall Event Capacity**. 
If your venue holds 500 people, enter 500. Even if you create multiple ticket tiers (like 300 Early Bird and 300 General Admission), the system will automatically halt ALL sales the moment the *total* tickets sold reaches 500, preventing dangerous overcrowding.

## Adding Ticket Tiers
You can create as many specific ticket types as you need.
1. Scroll to the **Ticket Tiers** section.
2. Click **Add Tier**.
3. Define the **Name** (e.g., "Early Bird"), **Price** (or $0 for Free), and **Inventory Limit** (how many of *this specific ticket* are available).
4. *Optional:* You can stagger ticket releases by setting "Start Sales" and "End Sales" times for each tier.

If an individual tier sells out, its specific Waitlist will activate, while other tiers may remain open.

## Adding Sponsors
If your event is financially supported by brands, you can feature them on the event page.
1. Go to the **Sponsors** tab in your dashboard.
2. Upload the sponsor's Logo and Name.
3. When creating or editing an event, select the sponsor from the dropdown menu to link them to the event.
