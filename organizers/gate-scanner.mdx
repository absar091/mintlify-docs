    # Operating the Gate Scanner

    The **UniTix Gate Scanner** is an attendee verification application available as a native **Android APK** and a responsive **Web App** (`unitix.aarx.online/scan`). It allows event staff to verify attendees rapidly while preventing ticket duplication, screenshots, and cross-gate double entry.

    ---

    ## 1. Attendance Metrics Dashboard
    The Gate Scanner features a 4-metric live header bar:

    | Metric | Formula | Operational Meaning |
    | :--- | :--- | :--- |
    | **Tickets Sold** | Total Issued | Total valid event passes purchased or claimed. |
    | **Checked In** | Verified Count | Total attendees admitted through the entrance gates today. |
    | **Remaining** | Sold - Checked In | Valid ticket holders who have not yet entered the venue. |
    | **Max Capacity** | Safety Limit | Total venue seating or safety occupancy limit. |

    ---

    ## 2. Three Scan Validation Modes

    The scanner automatically adapts to venue network conditions:

    ### A. Online Cloud Direct Mode (Default)
    - **How It Works**: The scanner transmits ticket scans directly to the secure cloud over 4G/5G or venue Wi-Fi.
    - **Speed**: Sub-second verification.
    - **Double-Entry Lock**: Real-time locking prevents a pass from being used twice across any gate.

    ### B. Offline Mode (Zero Internet)
    - **How It Works**: Before entering remote or underground halls, staff tap **Download Manifest**. The app downloads the verified attendee list locally.
    - **Offline Verification**: The scanner validates dynamic passes completely offline.
    - **Automatic Sync**: Scans are stored locally and automatically uploaded to the cloud once an internet connection is available.

    ### C. Multi-Gate Peer Mode (Multi-Gate Offline)
    - **How It Works**: One scanner phone acts as the central hub, while other gate phones connect wirelessly over local Wi-Fi or Bluetooth.
    - **Instant Cross-Gate Sync**: When Gate 1 admits an attendee, all other gates are instantly notified on-site within milliseconds.
    - **Double-Entry Prevention**: If the same pass is presented at Gate 2 simultaneously, it is immediately rejected.

    ---

    ## 3. How to Operate the Scanner App

    1. **Login**: Enter authorized scanner staff credentials.
    2. **Select Event**: Pick the active event from the list.
    3. **Scan Ticket**: Point the rear camera at the attendee's digital pass.
    4. **Observe Response State**:

    | Alert State | Visual & Audio Indicator | Meaning & Gate Protocol |
    | :--- | :--- | :--- |
    | **Valid / Checked In** | Green Screen + Beep | Ticket is authentic and unused. Displays Attendee Name, Roll Number, and Tier. **Admit Attendee.** |
    | **Already Used** | Red Screen + Buzz | Ticket was previously scanned today. Displays first check-in time and gate ID. **Deny Entry.** |
    | **Wrong Event** | Amber Screen + Beep | Ticket is valid but issued for a different event gate. **Redirect Attendee.** |
    | **Revoked / Cancelled** | Red Warning Screen | Pass was cancelled, refunded, or transferred away. **Deny Entry.** |
    | **Expired Dynamic Pass** | Grey Warning Screen | Attendee presented an expired screenshot. **Ask for live app view.** |

    ---

    ## 4. Multi-Tenant Society Protection
    - **Society Isolation**: Staff assigned to Society A cannot scan tickets for Society B, preventing unauthorized access in multi-society campuses.

    سکینر ایپ کی سکرین پر چار اہم معلومات ظاہر ہوتی ہیں:

    | اعدادوشمار | فارمولا | مطلب اور اہمیت |
    | :--- | :--- | :--- |
    | **Tickets Sold** | کل فروخت | ایونٹ کے لیے جاری کردہ کل تصدیق شدہ پاسز۔ |
    | **Checked In** | داخل شدہ افراد | وہ افراد جن کے ٹکٹ گیٹ پر سکین ہو کر اندر جا چکے ہیں۔ |

    ## 2. سکیننگ کے تین طریقے

    ### الف. آن لائن کلاؤڈ موڈ (Online Mode)
    - جب موبائل انٹرنیٹ یا وائی فائی سے جڑا ہو، تو ہر ٹکٹ فوری طور پر کلاؤڈ سرور پر تصدیق ہو کر محفوظ ہو جاتا ہے۔

    ### ب. آف لائن موڈ (Offline Mode)
    - جہاں انٹرنیٹ بالکل نہ ہو، وہاں عملہ ایونٹ شروع ہونے سے پہلے **Download Manifest** کا بٹن دبا کر لسٹ ڈاؤن لوڈ کر لیتا ہے۔ ایپ بغیر انٹرنیٹ کے ٹکٹ کی تصدیق کرتی ہے اور انٹرنیٹ آنے پر تمام ڈیٹا خود بخود اپ ڈیٹ ہو جاتا ہے۔

    ### ج. ایک سے زیادہ گیٹس کا رابطہ (Peer Mode)
    - بغیر انٹرنیٹ کے تمام گیٹس کے موبائل آپس میں جڑ جاتے ہیں۔ ایک گیٹ پر سکین ہونے والا ٹکٹ دوسرے تمام گیٹس پر فوراً بلاک ہو جاتا ہے۔
