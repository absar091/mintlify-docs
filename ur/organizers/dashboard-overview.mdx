# سوسائٹی ڈیش بورڈ کا تفصیلی جائزہ

    **سوسائٹی ڈیش بورڈ** (`/society-dashboard`) سوسائٹی کی قیادت، ایونٹ مینیجرز اور فنانس ٹیم کے لیے مرکزی کنٹرول روم ہے۔

    ---

    ## 1. اہم معلوماتی کارڈز

    | کارڈ | مطلب اور تفصیل |
    | :--- | :--- |
    | **کل آمدن (Gross Revenue)** | تمام ایونٹس کے بک شدہ ٹکٹوں کی کل رقم۔ |
    | **فروخت شدہ ٹکٹ** | تمام فعال ایونٹس کے جاری کردہ پاسز کی تعداد۔ |
    | **آنے والے ایونٹس** | موجودہ لائیو اور شیڈولڈ ایونٹس کی تعداد۔ |
    | **والیٹ بیلنس** | بینک اکاؤنٹ میں منتقلی کے لیے تیار رقم۔ |

    ---

    ## 2. لائیو چارٹس اور تجزیہ
    - **آمدن کا چارٹ**: روزانہ ٹکٹوں کی فروخت کا گراف تاکہ پتا چلے کہ کس دن سب سے زیادہ ٹکٹ فروخت ہوئے۔
    - **ٹکٹ کیٹیگری چارٹ**: ارلی برڈ، جنرل اور وی آئی پی ٹکٹوں کی فروخت کا موازنہ۔
    - **فوری بٹنز**: نیا ایونٹ بنانے، مارکیٹنگ ہب کھولنے اور لائیو گیٹ دیکھنے کے شارٹ کٹس۔
